# 玩家手册 · 晚风小路

## 启动
用浏览器打开 `Web004/index.html`（支持直接 `file://` 打开，无需构建）。

游戏内也可点主页 **「怎么玩」** 查看摘要。

## 核心循环
散步收集 → 窗台种植与收获 → 汽水铺招待客人 → 图鉴 / 手帐 / 成就记录。

**没有战斗、没有血量、没有倒计时失败。**

## 操作一览

### 通用
| 操作 | 说明 |
|------|------|
| 数字键 1–4 | 小路 / 盆栽 / 汽水铺 / 图鉴 |
| 主页按钮 | 季节、手帐、成就、设置、帮助、今日目标、演示、背包 |

### 晚风小路
- 屏幕 ◀ ▶ 或方向键 / `A` `D` 移动
- 靠近发光物自动拾取
- 主题芯片：枫叶小径 / 河畔漫步 / 竹影走廊 / 星光尾声（改天空、生成倾向、氛围）
- 「再走一段新路」：新地图 + 可能触发晚间 vignette 事件

### 窗台盆栽
1. 点空花盆  
2. 从种子列表种植（背包中的可种植物）  
3. 浇水 / 日照 / 说话推进生长  
4. 成熟后收获  
5. 「取个小名」为植物命名  
6. 金币足够时可扩展花盆（最多 6）

### 青柠汽水铺
杯型 → 基底 → 风味 → 装饰 → 端给客人。  
高分有金币与好心情；熟悉的客人会显示熟悉度。  
图鉴「秘密配方」页可查看已解锁配方。

### 今日小目标
每日 3 项温和目标，全部完成可领奖励；**未完成无任何惩罚**。

### 设置
- 轻音效反馈（WebAudio 合成，无外部音源文件）
- 减少动效
- 显示小提示
- 存档导出 / 导入（JSON 文本）

### 演示模式
一键载入展示用存档（建议先导出当前进度备份）。

## 常见问题
**Q: 材料不够？** 去小路拾取或照料盆栽收获。  
**Q: 存档丢了？** 设置里导出 JSON 自行备份。  
**Q: 能不能失败？** 核心循环没有失败结局。

## 技术说明（玩家可读）
纯前端 HTML/CSS/JS，本地 `localStorage` 存档。开发与测试见 `README.md`。
