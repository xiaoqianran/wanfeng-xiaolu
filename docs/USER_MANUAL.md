# 玩家手册 · 晚风小路

## 启动
用浏览器打开 `Web004/index.html`（支持 `file://`）。
游戏内点 **「怎么玩」** 或按 `?` / `H` 查看摘要。

## 核心循环
**纯静物养成** · **散步收集** · **小店搭配**

散步收集 → 窗台种植与收获 → 汽水铺招待客人 → 图鉴 / 手帐 / 成就。

**没有战斗、没有血量、没有倒计时失败。**

### 窗台盆栽（纯静物养成）
1. 选空花盆并种植种子（野果、草药、花瓣类可种的都会在列表显示）
2. 浇水 / **用水壶**（额外水分，需散步蓄水；可用金币**扩大水壶**至 8 格）/ 日照 / 说话 / **歇一歇**
3. **季节照料**：春说话、夏日照、秋浇水、冬歇息有轻微软加成
4. 成熟后收获；高心情可能附赠小礼物
5. 取小名、写便签、**窗台速写**；同一花盆多次收获会积累**熟土记忆**（额外产量）
6. 金币可扩展花盆（最多 6）；可用**对调花盆**整理窗台顺序
7. 茴香籽、佛手柑、香菜、紫罗兰、金盏花、香蜂草、姜等可种在窗台；收获后继续用于汽水风味
8. **晨露**：离开较久再回来，植物会轻轻回一点水分与心情（不是惩罚系统）
9. **晨间照料**：每天第一次照料，水分与心情会多一点点
10. **邻盆作伴**：窗台有两盆以上植物时，照料会多一点心情（很轻）
11. **多样窗台**：三种以上不同植物时，照料再多一点点心情
12. **最想照料**：可标记一盆最想照料的植物，照料时心情略增

### 青柠汽水铺（小店搭配）
杯型 → 基底 → 风味 → 装饰 → 端给客人。

- 匹配客人标签 / 风味记忆 / 熟悉度可加分与小费
- 季节会软影响评分（如春日花香、冬日暖茶）
- 接近秘密配方时，预览名会提示「隐约接近」
- 「今日展示架」保留最近 3 杯影子
- **记为常客**：提高该客人再来概率
- **客人便签**：给客人写一句软提醒（不是订单系统）
- **老样子**：填入该客人上次配方；连做相同搭配有软小费
- **常用此杯**：记住杯型，下次默认选中
- **今日小特调**：按季节与日期推荐风味方向，命中有软奖励（非强制）
- **小费罐**：好评出杯攒罐，满 10 换 1 好心情
- **常客小黑板**：熟悉度高的客人名字会轻轻写在展示架旁（不是排行榜）
- **钉住配方**：把当前搭配或命中的秘密配方钉在柜台，可一键填回
- **开店清静**：每天前 3 杯出杯有轻微软奖励（不是倒计时）
- **温柔收摊**：一天一次，把出杯与小费罐记入手帐（不是失败结算）
- 安静模式可简化需求；连胜有小奖励

## 常见问题
**材料不够？** 去小路或照料盆栽。  
**水壶空了？** 再走一段新路或长椅歇脚蓄水。  
**存档？** 设置中导出/复制 JSON。  
**会失败吗？** 核心循环没有失败结局。
