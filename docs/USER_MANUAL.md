# 玩家手册 · 晚风小路

## 启动
用浏览器打开 `Web004/index.html`（支持 `file://`）。
游戏内点 **「怎么玩」** 或按 `?` / `H` 查看摘要。

## 核心循环
**纯静物养成** · **散步收集** · **小店搭配**

散步收集 → 窗台种植与收获 → 汽水铺招待客人 → 图鉴 / 手帐 / 成就。

**没有战斗、没有血量、没有倒计时失败。**

### 窗台盆栽（纯静物养成）
1. 选空花盆并种植种子（野果、草药、花瓣类可种的都会在列表显示）
2. 浇水 / **用水壶**（额外水分，需散步蓄水；可用金币**扩大水壶**至 8 格）/ 日照 / 说话 / **歇一歇**

4. 成熟后收获；高心情可能附赠小礼物
5. 取小名、写便签、**窗台速写**；同一花盆多次收获会积累**熟土记忆**（额外产量）

9. **晨间照料**：每天第一次照料，水分与心情会多一点点
10. **邻盆作伴**：窗台有两盆以上植物时，照料会多一点心情（很轻）
11. **多样窗台**：三种以上不同植物时，照料再多一点点心情
12. **最想照料**：可标记一盆最想照料的植物，照料时心情略增
