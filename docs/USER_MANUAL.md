# 玩家手册 · 晚风小路

## 启动
用浏览器打开 `Web004/index.html`（支持 `file://`）。
游戏内点 **「怎么玩」** 或按 `?` / `H` 查看摘要。

## 核心循环
散步收集 → 窗台种植与收获 → 汽水铺招待客人 → 图鉴 / 手帐 / 成就。

**没有战斗、没有血量、没有倒计时失败。**

## 操作一览

### 通用快捷键
| 键 | 作用 |
|----|------|
| 1–4 | 小路 / 盆栽 / 汽水铺 / 图鉴 |
| Esc | 回小院 |
| B | 背包 |
| M | 信箱 |
| ? / H | 怎么玩 |

### 晚风小路
- 屏幕按钮或方向键 / `A` `D` 移动，靠近发光物拾取
- 主题：枫径、河畔、竹影、星光、草甸、码头、灯笼小巷、屋檐听雨
- 「再走一段新路」：新地图 + 可能触发晚间事件

### 窗台盆栽
1. 选空花盆并种植种子  
2. 浇水 / 日照 / 说话 / **歇一歇**（恢复心情，几乎不催长）  
3. 成熟后收获；高心情可能附赠小礼物  
4. 取小名；金币可扩展花盆（最多 6）

### 青柠汽水铺
杯型 → 基底 → 风味 → 装饰 → 端给客人。  
安静模式可简化需求；连胜有小奖励；图鉴可看秘密配方。

### 今日小目标 / 信箱 / 足迹
- 日目标：完成可领金币、好心情与日礼  
- 信箱：拆开来信获得小奖励  
- 足迹：查看统计（不是排行榜）

### 设置
音效、减少动效、天气特效、环境底噪、安静模式、存档导出/导入/复制、新的一天、重看引导。

### 演示模式
一键载入展示存档（建议先导出备份）。

## 常见问题
**材料不够？** 去小路或照料盆栽。  
**存档？** 设置中导出/复制 JSON。  
**会失败吗？** 核心循环没有失败结局。
