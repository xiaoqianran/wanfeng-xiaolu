# 玩家手册 · 晚风小路

## 启动
用浏览器打开 `Web004/index.html`（支持 `file://`）。
游戏内点 **「怎么玩」** 或按 `?` / `H` 查看摘要。

## 核心循环
**纯静物养成** · **散步收集** · **小店搭配**

散步收集 → 窗台种植与收获 → 汽水铺招待客人 → 图鉴 / 手帐 / 成就。

**没有战斗、没有血量、没有倒计时失败。**

## 操作一览

| 键 | 作用 |

### 晚风小路（散步收集）
- 屏幕按钮或方向键 / `A` `D` 移动，靠近发光物拾取
- 主题（影响天空、天气粒子与拾取偏向）：
  - 枫叶小径、河畔漫步、竹影走廊、星光尾声
  - 草甸慢坡、码头薄暮、灯笼小巷、屋檐听雨
  - 花市巷尾、旧书庭院、梅影短径、雾桥轻步、萤火浅坡、夜市尾声、石庭慢转、雪灯小径、晨桥薄雾、云台慢坡、潮间小湾
- 「再走一段新路」：新地图 + 可能触发晚间事件 + **水壶蓄一格水**；**今日第一脚**额外软奖励（每日一次）；走满 5/15/30/50 段可获**小路贴纸**
- 「长椅歇脚」：安静坐下；每 3 次 +1 好心情，也会给水壶蓄水
- 「标为常走」：记住当前小路主题，主题条会显示 ★

### 窗台盆栽（纯静物养成）
1. 选空花盆并种植种子（野果、草药、花瓣类可种的都会在列表显示）
2. 浇水 / **用水壶**（额外水分，需散步蓄水）/ 日照 / 说话 / **歇一歇**
3. **季节照料**：春说话、夏日照、秋浇水、冬歇息有轻微软加成
4. 成熟后收获；高心情可能附赠小礼物
5. 取小名、写便签、**窗台速写**；同一花盆多次收获会积累**熟土记忆**（额外产量）
6. 金币可扩展花盆（最多 6）

### 青柠汽水铺（小店搭配）
杯型 → 基底 → 风味 → 装饰 → 端给客人。

- 匹配客人标签 / 风味记忆 / 熟悉度可加分与小费
- 季节会软影响评分（如春日花香、冬日暖茶）
- 接近秘密配方时，预览名会提示「隐约接近」
- 「今日展示架」保留最近 3 杯影子
- **记为常客**：提高该客人再来概率
- **老样子**：填入该客人上次配方；连做相同搭配有软小费
- 安静模式可简化需求；连胜有小奖励

### 图鉴日记
- 收集物 / 盆栽 / 汽水 / 秘密配方
- 收集物可按 **装饰 · 风味 · 基底 · 收藏** 筛选（会隐藏模板批量条目）

### 今日小目标 / 信箱 / 足迹
- 日目标：含散步、拾取、照料、出杯、手帐、**便签**、**长椅** 等；完成可领奖励
- 信箱：拆开来信获得小奖励
- 足迹：统计与常来客人，不是排行榜

### 设置
音效、减少动效、天气特效、环境底噪、安静模式、存档导出/导入/复制、新的一天、重看引导。

### 演示模式
一键载入展示存档（建议先导出备份）。

## 常见问题
**材料不够？** 去小路或照料盆栽。  
**水壶空了？** 再走一段新路或长椅歇脚蓄水。  
**存档？** 设置中导出/复制 JSON。  
**会失败吗？** 核心循环没有失败结局。
