# 玩家手册 · 晚风小路

## 启动
用浏览器打开 `Web004/index.html`（支持 `file://`）。
游戏内点 **「怎么玩」** 或按 `?` / `H` 查看摘要。

## 核心循环
**纯静物养成** · **散步收集** · **小店搭配**

散步收集 → 窗台种植与收获 → 汽水铺招待客人 → 图鉴 / 手帐 / 成就。

**没有战斗、没有血量、没有倒计时失败。**

- **开店清静**：每天前 3 杯出杯有轻微软奖励（不是倒计时）
- **温柔收摊**：一天一次，把出杯与小费罐记入手帐（不是失败结算）
- 安静模式可简化需求；连胜有小奖励

## 常见问题
**材料不够？** 去小路或照料盆栽。  
**水壶空了？** 再走一段新路或长椅歇脚蓄水。  
**存档？** 设置中导出/复制 JSON。  
**会失败吗？** 核心循环没有失败结局。
