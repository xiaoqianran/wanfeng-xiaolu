# 创新点与限制

## 创新点
1. **无压力治愈循环**：散步-盆栽-汽水闭环，无战斗/无失败惩罚。  
2. **file:// 可运行架构**：纯逻辑与 DOM 分离，双 bundle 同步保证 content 可测。  
3. **主题化小路**：主题同时改天空、生成权重与氛围文案。  
4. **数据驱动秘密配方与晚间事件**：内容扩展不改引擎。  
5. **诚实进度账本**：authentic 与模板刷轮分离，质量门禁可自动校验。

## 已知限制
- authentic 轮次远未达 1000（真实 30 分钟工作量跨会话累积）。  
- 生图 API 不稳定，部分 UI 使用程序化独特图标。  
- 无障碍为渐进增强，未做完整读屏专项测评。  
- 音频为合成音，非录制 BGM。
