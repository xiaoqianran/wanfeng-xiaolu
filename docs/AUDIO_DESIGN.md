# 音频需求设计 · 晚风小路

## 原则
- 轻、短、可关；不抢文案与画面。
- 默认 WebAudio 合成，无外部版权音源依赖。
- 设置「轻音效反馈」关闭时全部静音。

## 事件表
| 事件 | kind | 意图 |
|------|------|------|
| 拾取 | pickup | 清脆短音 |
| 浇水 | water | 偏低柔和 |
| 出杯 | serve | 稍亮完成感 |
| UI | ui | 极轻点击 |
| 收获 | harvest | 柔和上扬 |
| 解锁花盆 | unlock | 短促确认 |
| 切换主题 | theme | 过渡感 |
| 成就 | achieve | 更长一点的柔和音 |
