# 毕业设计演示脚本（约 5 分钟）

1. **打开** `Web004/index.html`（file://）。  
2. **引导**：快速点完或跳过。  
3. **演示模式**：点「演示模式」载入展示存档。  
4. **散步**：进入晚风小路，左右移动拾取 1–2 件。  
5. **盆栽**：窗台浇水/日照，展示生长条。  
6. **汽水铺**：按客人标签选基底与风味，端出。  
7. **今日小目标**：展示进度，说明无惩罚。  
8. **图鉴/手帐/成就**：翻看记录。  
9. **设置**：开关音效、导出存档一行 JSON。  
10. **收尾**：强调无战斗、小清新、纯前端可展示。
