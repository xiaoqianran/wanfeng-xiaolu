# 游戏设计文档 · 晚风小路

## 一句话
在温柔的黄昏小路散步拾取、在窗台照料盆栽、为过路人调制汽水——没有打斗，只有日常。

## 类型与受众
- 类型：治愈 / 轻经营 / 收集
- 受众：毕业设计展示、休闲玩家
- 单局时长：3–15 分钟可中断

## 核心循环
1. **散步**：左右移动，拾取落叶/果子/草药  
2. **盆栽**：种植、浇水、日照、说话、收获  
3. **汽水铺**：杯型 × 基底 × 风味 × 装饰，按客人偏好打分  
4. **图鉴 / 手帐 / 成就 / 季节**：记录与长期目标  

## 胜负与压力
- **无战斗、无 HP、无倒计时失败**  
- 客人永远接纳；高分有金币与好心情奖励  

## 系统一览
| 系统 | 说明 |
|------|------|
| 背包/发现 | 拾取写入 bag + discovered |
| 盆栽 | 水分/日照/心情驱动生长 |
| 调制 | scoreDrink / serveDrink 纯逻辑 |
| 季节 | dusk→春夏秋冬，换 banner 艺术 |
| 存档 | localStorage + Core.serialize |

## 非目标
战斗、PvP、联机、恐怖、付费墙。


## 扩展系统（持续迭代）
- 小路主题（枫/河/竹/星/草甸/码头）与天气特效
- 今日小目标 + 日礼、信箱、足迹、演示模式
- 秘密配方图鉴、植物小名、花盆扩展
- 季节评分加成、客人熟悉度与风味记忆
- 设置：音效 / 动效 / 天气 / 存档导入导出 / 新的一天
